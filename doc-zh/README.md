## 翻译约定

- 正文、表格和清单按原文完整翻译，保留限制条件与例子。
- 代码块、命令、配置键、API 标识符和 Mermaid 源码保持原样；代码中的英文注释也保留，便于与实现对照。
- 术语沿用原文的中英对照表，例如 Trigger 为“触发”、Thread 为“线程”、Mandate 为“授权”、Ticket 为“工单”、Assignment 为“派工”。完整术语见 [001 领域模型的术语表](001-domain.md#glossary)。
- 本文档中的 Thread 表示相关事件或讨论组成的线程，不是操作系统线程；Eval 表示工作准入与判断过程，不是模型基准测试。
- 为方便跳转与显示，译文保留英文标题锚点，并对表格中的竖线作必要的 Markdown 转义；代码显示值不变。
